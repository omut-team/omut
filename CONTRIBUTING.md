Подробно и с кнопками GitHub Desktop (Windows и Mac): [docs/SETUP.md, часть 8](docs/SETUP.md#часть-8-как-сдавать-работу-каждый-день).

## Ветки

```
main     ← только рабочие версии (патчи 0.1, 0.2 ...). Напрямую не пушим.
dev      ← общая ветка разработки. Сюда сливаются все задачи.
<тип>/<что-делаю>   ← твоя ветка под одну задачу
```

| Тип ветки | Кто | Пример |
|---|---|---|
| `feature/` | Ярослав, код (имя ветки из этапа в [PLAN.md](docs/PLAN.md)) | `feature/boat-movement` |
| `art/` | Ульяна, Лиза | `art/fish-day` |
| `sound/` | Лиза | `sound/fishing-sfx` |
| `level/` | Лиза, Илья | `level/bay-zone` |
| `balance/` | Илья | `balance/fish-0-2` |
| `docs/` | Сарина, все | `docs/use-case` |
| `fix/` | все | `fix/inventory-drag` |

## Порядок работы над задачей

1. Взять задачу на [доске](https://github.com/orgs/omut-team/projects/1), назначить себя и перетащить в **In Progress**. Новые задачи через Issues сами попадают на доску.
2. Обновить `dev` и сделать от неё свою ветку:
   ```bash
   git checkout dev
   git pull
   git checkout -b art/fish-day
   ```
3. Сделать задачу, коммитить небольшими кусками. Файлы класть только в **свои папки** (таблица ниже).
4. Отправить ветку и открыть Pull Request **в `dev`**:
   ```bash
   git push -u origin art/fish-day
   ```
5. В описании PR написать `Closes #номер_задачи`.
6. Дождаться проверки, после этого PR сливается.

## Кто проверяет

| Что | Кто проверяет |
|---|---|
| Код Ярослава | Илья |
| Баланс Ильи | Ярослав (не ломает ли логику), Сарина (в игре) |
| Арт и звук | Илья (стиль, размер), Ярослав (встаёт ли в игру) |
| Тексты и документы | Илья |
| Патч целиком | Сарина по тест-кейсам |

В конце патча Илья сливает `dev` в `main` и выкладывает сборку в Releases.

## Правила Unity (чтобы не ломать друг другу проект)

1. **Общую сцену `Main` правит только Илья.** Остальные работают в своих тестовых сценах `Sandbox_<Имя>`.
2. Всё, что можно, делаем **префабами**. Префаб правит один человек за раз.
3. Перед тем как открыть Unity, сделай `git pull`.
4. Не коммить папки `Library`, `Temp`, `Logs`, `UserSettings`. Они уже в `.gitignore`.
5. Файл `.meta` всегда коммитится **вместе** со своим файлом.
6. Версия Unity у всех одинаковая: **6000.3.28f1** (см. [docs/SETUP.md](docs/SETUP.md)).
