# Сайт рекордов

Простая страница на HTML/JS, отдаётся через nginx. Запросы `/api/...` nginx передаёт серверу.
Отвечает: Ярослав. Сейчас показывает заглушку, настоящие рекорды появятся в патче 0.4 (этап 21 в [docs/PLAN.md](../docs/PLAN.md)).

Открыть: `docker compose up`, потом http://localhost:8080
