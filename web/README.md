# Сайт рекордов

Одна страница на HTML/JS (`index.html`), отдаётся через nginx (`nginx.conf`). Запросы `/api/...` nginx передаёт серверу игры.
Отвечает: Ярослав.

Открыть: из корня репозитория `docker compose up --build`, потом http://localhost:8080

Что на странице:
- сколько рыбаков, трофеев и килограммов;
- «Самые тяжёлые»: топ-20 трофеев, можно выбрать вид рыбы;
- «Рекорд каждого вида»: самая большая рыба каждого вида и кто поймал;
- «Лучшие рыбаки»: сколько трофеев, сколько кг, самая большая рыба, на какую сумму;
- «Последние уловы»: что ловили недавно, днём или ночью, в какой зоне.

Страница обновляется сама каждые 30 секунд. Имена игроков выводятся только как текст (без HTML), чтобы никто не вставил свой код.

Трофеи попадают сюда из игры: главное меню, «Онлайн-рекорды», войти или зарегистрироваться, потом ловить рыбу.
