# Команда и роли

Роли предварительные, их можно поменять на общем созвоне.

## Илья: тимлид, разработчик

**Как тимлид:**
- ведёт задачи в Issues, раздаёт их по патчам и следит за сроками;
- проверяет pull request'ы в `dev` и сливает `dev` в `main` в конце патча;
- проводит короткие созвоны раз в неделю (что сделал, что дальше, что мешает).

**Как разработчик:**
- рыбалка: заброс, поклёвка, мини-игра вываживания, поведение рыб;
- трюм-сетка (перетаскивание, поворот, вес);
- NPC, диалоги, квесты, магазин.

Папки: `game/Assets/Scripts/Fishing`, `Inventory`, `NPC`, `UI`

## Ярослав: разработчик

- ядро игры: GameManager, состояния игры, события;
- лодка и её физика, ходьба по суше, камера;
- день и ночь, туман, фонарь, паника;
- сохранения и настройки;
- сервер (ASP.NET Core + PostgreSQL), сайт рекордов, Docker Compose;
- репозиторий: структура, `.gitignore`, Git LFS, помощь всем с git.

Папки: `game/Assets/Scripts/Core`, `Player`, `World`, `Network`, `server/`, `web/`

## Ульяна: дизайнер (персонажи и интерфейс)

- герой, NPC (Тарас, Михалыч, Ядвига, Гануля) и их портреты для диалогов;
- все рыбы, включая ночных мутантов;
- предметы и иконки (снасти, керосин, записки, металлолом);
- интерфейс: HUD, трюм, журнал, магазин, меню;
- анимации: лодка, поплавок, всплески.

Папки: `game/Assets/Art/Characters`, `Fish`, `Items`, `UI`, исходники в `design/`

## Лиза: дизайнер (мир и звук)

- тайлсеты: вода, берег, причал, деревня, камыш, коряги;
- сборка локаций в Unity через Tilemap (залив, затопленный лес, глубь, остров);
- свет и атмосфера: ночь, туман, светящиеся объекты;
- подбор звуков и музыки (бесплатные, с правильной лицензией);
- логотип и обложка для презентации.

Папки: `game/Assets/Art/Tiles`, `Environment`, `game/Assets/Audio`, сцены своих локаций

## Сарина: тестировщик, документовед, сценарист

- ТЗ: цели, аудитория, требования, user stories;
- диаграммы: вариантов использования, последовательности, состояний, активности, BPMN, DFD, ER, развёртывания;
- тест-кейсы (30+), проверка каждого патча, баг-репорты в Issues;
- тексты: диалоги NPC, записки дядьки, описания рыб, квесты;
- README, руководство пользователя, итоговая презентация.

Папки: `docs/`, тексты в `game/Assets/Data/Dialogues`

## Кто кого проверяет

| Что сделано | Кто проверяет |
|---|---|
| Код Ярослава | Илья |
| Код Ильи | Ярослав |
| Арт | Илья (подходит ли по стилю и размеру) |
| Каждый патч целиком | Сарина (по тест-кейсам) |
| Документы | Илья |
