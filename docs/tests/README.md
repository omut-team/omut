# Тест-кейсы

Отвечает: Сарина. Цель: 30+ тест-кейсов к патчу 0.4, плюс полная проверка релиза 1.0.
Проверяем сборку `.exe` из Releases (Windows 10/11). Какие этапы входят в патч: [PLAN.md](../PLAN.md).

## Как оформлять

- Номер: `TC-<патч>-<номер>`, например `TC-0.2-03`. Номера не меняем, даже если кейс удалили.
- Один кейс проверяет одну вещь.
- «Результат»: ✅ прошёл, ❌ не прошёл (и ссылка на баг `#номер`), ⏭ не проверяли.
- Не прошёл: создать задачу по шаблону **Баг** и вписать её номер.
