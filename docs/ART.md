# Гайд для дизайнеров

Что именно рисовать и к какому сроку: [TEAM_PLAN.md](TEAM_PLAN.md) (разделы Ульяны и Лизы). Мир игры: [PLAN.md](PLAN.md).

## Стиль

- Пиксель-арт, вид сверху под небольшим углом.
- Базовый размер клетки (тайла): **32x32 px**. В Unity 32 px = 1 клетка.
- **День:** тёплые цвета, зелень, золотой свет.
- **Ночь:** тёмно-синие и болотно-зелёные тона, туман. Светятся только фонарь лодки, маяк и ночные рыбы.
- Интерфейс в стиле старой тетради рыбака: бумага, карандаш, штампы.

**Правило для рыб:** размер картинки = размер в трюме x 32 px. Рыбу рисуем горизонтально, головой вправо. Поворот в трюме делает код.

Размеры окон интерфейса Ярослав допишет сюда после этапа 4, когда настроит экран.

## Формат и имена

- Экспорт в **PNG**, фон прозрачный, без сглаживания.
- Имена латиницей, маленькими буквами, через подчёркивание: `fish_pike.png`, `npc_taras_portrait.png`, `tile_water_01.png`, `ui_hold_bg.png`.
- Начало имени по типу: `boat_`, `hero_`, `npc_`, `fish_`, `item_`, `obj_`, `ui_`, `tile_`, `env_`, `fx_`, `logo_`, `cover_`.
- Анимация: отдельный лист кадров (spritesheet), кадры одинакового размера в одну строку, в конце имени `_sheet`: `boat_barkas_idle_sheet.png`.
- Панели интерфейса рисуй так, чтобы края можно было растянуть (9-slice).
- Полный список имён файлов по этапам: [TEAM_PLAN.md](TEAM_PLAN.md).

## Звук (для Лизы)

- Музыка в `.ogg`, короткие звуки в `.wav`.
- Имена: `music_day.ogg`, `sfx_bell.wav` и так далее, список в [TEAM_PLAN.md](TEAM_PLAN.md#лиза).
- Громкость примерно одинаковая, без тишины в начале файла. Музыка зациклена без щелчка.

## Куда класть

| Кто | Что | Папка |
|---|---|---|
| Ульяна | готовые PNG | `design/export/boats/`, `characters/`, `fish/`, `items/`, `ui/` |
| Ульяна | исходники | `design/src/ulyana/` |
| Лиза | тайлы и окружение (импорт в Unity сама) | `game/Assets/Art/Tiles/`, `game/Assets/Art/Environment/` |
| Лиза | зоны на Tilemap | `game/Assets/Prefabs/Zones/` |
| Лиза | музыка и звуки | `game/Assets/Audio/Music/`, `game/Assets/Audio/SFX/` |
| Лиза | исходники; логотип и обложка | `design/src/liza/`; `design/export/brand/` |

Ульяна в `game/` не коммитит: Ярослав забирает картинки из `design/export/` и подключает их сам. Так у картинок не появятся два разных `.meta`.

Если перерисовала картинку, просто замени PNG в `design/export/` под **тем же именем** и напиши Ярославу. Новое имя = новая картинка.

## Как подключать арт в Unity

Это для Ярослава и Лизы (и для Ульяны, если она работает в Unity).

1. Перетащить PNG в нужную папку `game/Assets/Art/...` (лодки в `Art/Boats`, если папки нет, создать в Unity: правый клик → **Create → Folder**).
2. В инспекторе картинки:
   - **Texture Type:** Sprite (2D and UI);
   - **Pixels Per Unit:** 32;
   - **Filter Mode:** Point (no filter);
   - **Compression:** None;
   - для листа кадров **Sprite Mode:** Multiple → **Sprite Editor → Slice → Grid By Cell Size** (размер кадра).
3. **Apply**.
4. Закоммитить PNG **вместе с `.meta`**.

## Программы

Все работают на Windows и на Mac:
- **Aseprite** (платный, удобнее всего для пиксель-арта) или бесплатные **LibreSprite** и **Pixelorama**.
- Для крупных картинок (обложка, карта): **Krita** (бесплатно).
- Звук: **Audacity** (бесплатно), чтобы обрезать и выровнять громкость.
