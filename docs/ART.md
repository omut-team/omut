# Гайд для дизайнеров

## Стиль

- Пиксель-арт, вид сверху под небольшим углом.
- Базовый размер клетки (тайла): **32x32 px**.
- **День:** тёплые цвета, зелень, золотой свет.
- **Ночь:** тёмно-синие и болотно-зелёные тона. Светятся только фонарь, ночные рыбы и блуждающие огни.
- Интерфейс в стиле старой тетради рыбака: бумага, карандаш, штампы.

## Размеры

| Что | Размер |
|---|---|
| Тайл (вода, берег, причал) | 32x32 |
| Герой, NPC | 32x48 |
| Лодка | 64x32 |
| Маленькая рыба (1 клетка трюма) | 32x32 |
| Щука (1x3) | 96x32 |
| Сом (2x3) | 96x64 |
| Иконка предмета | 32x32 |
| Портрет NPC для диалога | 96x96 |

## Формат и имена

- Экспорт в **PNG**, фон прозрачный.
- Имена латиницей, маленькими буквами, через подчёркивание:
  `fish_pike.png`, `npc_taras_portrait.png`, `tile_water_01.png`, `ui_inventory_bg.png`
- Анимация: отдельный лист кадров (spritesheet), кадры в одну строку: `boat_idle_sheet.png`.

## Куда класть

| Что | Папка |
|---|---|
| Готовые PNG для игры | `game/Assets/Art/...` (Characters, Fish, Items, UI, Tiles, Environment) |
| Исходники (.psd, .aseprite, .kra) | `design/` |
| Звуки и музыка | `game/Assets/Audio/SFX` и `game/Assets/Audio/Music` |

## Готовые ресурсы

Можно брать только бесплатное с подходящей лицензией (CC0 или с разрешением на использование). Ссылку и лицензию записывай в [CREDITS.md](CREDITS.md).

Где искать:
- https://itch.io/game-assets/free (фильтр Pixel Art)
- https://kenney.nl/assets
- https://opengameart.org
- звуки: https://freesound.org, https://pixabay.com/sound-effects

## Программы

- **Aseprite** (платный, удобнее всего для пиксель-арта) или бесплатный **LibreSprite** / **Pixelorama**.
- Для крупных картинок: **Krita** (бесплатно).
