# Как запустить «Омут»: от Unity Hub до сайта рекордов

Пошагово для Windows 10/11. Установка программ описана в [SETUP.md](SETUP.md), здесь только запуск.

Нужно: Unity Hub с Unity **6000.3.28f1**, Git, для сервера Docker Desktop.

## 1. Свежий код

1. Открой **GitHub Desktop**, слева вверху **Current repository: omut**.
2. **Current branch: dev** (если стоит другая ветка, переключись на `dev`).
3. Нажми **Fetch origin**, потом **Pull origin**.

Или в терминале (PowerShell) в папке проекта:

```bash
cd "C:\Users\USER\Desktop\ПО-2409\ТРПО\omut"
```

```bash
git checkout dev
```

```bash
git pull
```

## 2. Открыть проект в Unity Hub

1. Запусти **Unity Hub**.
2. Вкладка **Projects**. Если `game` уже в списке, просто нажми на него.
3. Если нет: **Add** (или **Open**) → **Add project from disk** → выбери папку `C:\Users\USER\Desktop\ПО-2409\ТРПО\omut\game` → **Add Project**.
4. Проверь, что справа у проекта стоит версия **6000.3.28f1**. Нажми на проект, Unity откроется (первый раз 3–10 минут, он импортирует всё).

## 3. Собрать сцену (один раз после каждого pull)

Сцена `Main` и данные игры собираются автоматически из кода, руками ничего расставлять не надо.

1. В верхнем меню Unity: **Omut → Собрать сцену Main**.
2. Внизу в Console появится «Сцена Main собрана».

Если правил числа рыб, лодок или тексты в коде таблиц (`Assets/Editor/OmutDataBuilder*.cs`): **Omut → Обновить данные игры (перезаписать)**, потом снова **Собрать сцену Main**.

## 4. Играть в редакторе

1. Внизу в окне **Project** открой `Assets/Scenes/Main.unity` (двойной щелчок).
2. Нажми **Play** (треугольник вверху по центру).
3. В главном меню **Новая игра**.

### Управление

| Клавиша | Что делает |
|---|---|
| WASD / стрелки | плыть на лодке или идти пешком |
| E | поговорить с NPC, причалить и сойти, сесть в лодку, открыть сундук |
| Space (зажать и отпустить) | заброс, целиться мышью |
| Space | подсечка при поклёвке, «В трюм» в карточке трофея |
| ЛКМ / ПКМ | тянуть / стравить леску при вываживании |
| 1-6 или колесо мыши | панель предметов внизу: 1 удочка с червём, 2 с блесной, 3 с фосфорной, 4 фонарь в руке, 5 чай, 6 карта |
| Q | сменить наживку |
| F | фонарь |
| C | выпить чай из термоса (страх −35) |
| Tab или I | трюм с рыбой (перетаскивать мышью, R повернуть) |
| B | сумка: все вещи (наживка, фонарь, термос, металлолом, страницы, монеты) |
| J | журнал рыб и дневник деда |
| M | карта |
| L | задания и тайны озера |
| Esc | пауза или закрыть окно |

Справа сверху список **«Что делать»**: главная цель жёлтая, к ней показывает стрелка у края экрана (с расстоянием). Над жителями таблички «Дед Тарас», «Михалыч»: **!** есть новое задание, **?** задание можно сдать. Реплики озвучены (громкость: Настройки → Голоса).

### Как пройти игру (для защиты)

1. Новая игра начинается у хаты деда. Подойди к **Тарасу** (у маяка) → E: знакомство и первое задание.
2. Дойди до конца мостков → **E: сесть в лодку**. Плыви на юг в **залив**, зажми Space, брось в круги на воде. На червя клюёт карась.
3. Подсечка Space, потом ЛКМ/ПКМ держи стрелку в зелёном. Карточка трофея → **В трюм**.
4. Вернись к мосткам → E, продай улов Тарасу, сдай задание, купи блёсны.
5. Восточнее **омут**: щука и судак на блесну (Q). Осторожно с корягами: Михалыч чинит.
6. В 20:00 бьёт **колокол**. Включи фонарь (F). Ночью рыба x3, но растёт страх. У маяка безопасно.
7. Ночью на **рифе** ловятся сундучки деда (5 страниц дневника). Все страницы → сундук на причале → письмо.
8. После письма ночью в центре омута водоворот: фосфорная блесна → **Хозяин Омута** → титры.

### Быстро проверить всё (читы для защиты)

Время можно проматывать в редакторе: **T** = +1 час, **Y** = сразу 19:55 (колокол через пару секунд).

## 5. Автотесты

1. **Window → General → Test Runner**.
2. Вкладка **EditMode** → **Run All**: около 150 тестов расчётов (часы, натяжение, трюм, квесты, паника...).
3. Вкладка **PlayMode** → **Run All**: запуск сцены Main и проверка рыбалки, причала, сохранений, обморока, финала.

Все должны быть зелёными. Тесты `ScreenshotTests` и `ServerIntegrationTests` пропускаются, если не задана переменная `OMUT_SCREENSHOTS=1` или `OMUT_SERVER=1`.

## 6. Сервер и сайт рекордов

1. Запусти **Docker Desktop** и подожди, пока внизу будет «Engine running».
2. В PowerShell в папке проекта:

```bash
cd "C:\Users\USER\Desktop\ПО-2409\ТРПО\omut"
```

```bash
docker compose up --build
```

3. Первый раз качается 1–2 ГБ (5–10 минут). Готово, когда в логе есть `api-1` без ошибок.
4. Открой в браузере:
   - сайт рекордов: http://localhost:8080
   - сервер: http://localhost:5000/api/health (должно быть `{"status":"ok"}`)
5. В игре: главное меню → **Онлайн-рекорды** → придумай имя и пароль → **Регистрация**. Теперь каждая пойманная рыба уходит на сайт.
6. Остановить сервер: в окне PowerShell **Ctrl+C**, потом:

```bash
docker compose down
```

Тесты сервера (нужен .NET SDK 10):

```bash
cd server/Omut.Api.Tests
```

```bash
dotnet test
```

## 7. Собрать .exe

1. В Unity: **Omut → Собрать .exe (Windows)**.
2. Через 2–5 минут откроется папка `omut\Builds\Omut` с `Omut.exe`.
3. Для сдачи заархивируй всю папку `Builds\Omut` (не только exe) и выложи в GitHub Releases.

## Если что-то не так

| Проблема | Что делать |
|---|---|
| В Console красные ошибки после pull | Закрыть Unity, удалить папку `game\Library`, открыть проект снова (долго, но лечит почти всё) |
| Сцена пустая или старая | **Omut → Собрать сцену Main** |
| «Сервер не отвечает» в игре | Запущен ли Docker Desktop и `docker compose up`? Адрес в «Онлайн-рекорды» должен быть `http://localhost:5000` |
| Порт 5000 или 8080 занят | Закрыть программу, которая его держит, или поменять порты в `docker-compose.yml` |
| Хочу начать игру заново | Главное меню → **Новая игра** (старое сохранение перезапишется при следующем сохранении) |
| Где лежит сохранение | `%USERPROFILE%\AppData\LocalLow\omut-team\Омут\omut_save.json` |

## Как заменить заглушки на настоящий арт и звук

- Картинки: положить PNG с тем же именем, что у заглушки в `Assets/Art/Placeholders`, в нужную папку `Assets/Art/...` (например `Art/Fish/fish_pike.png`), потом **Omut → Обновить данные игры (перезаписать)** и **Собрать сцену Main**. Настоящая картинка важнее заглушки. Настройки импорта (32 PPU, Point, опора внизу у стоящих объектов) ставятся сами.
- Лодки Ульяны: большие PNG кладём в `design/export/boats`, потом `python tools/make_boats.py` уменьшает их до 64x48 в `Assets/Art/Boats`.
- Озвучка: после **Собрать сцену Main** реплики выгружаются в `tools/voice/lines.txt`, потом в PowerShell из корня репозитория `powershell -ExecutionPolicy Bypass -File tools\make_voice.ps1` (голос Windows «Pavel», без интернета). Новые файлы появятся в `Assets/Resources/Voice`. Нет файла: персонаж «бормочет».
- Звуки: `Assets/Audio/SFX/sfx_<id>.wav` (`sfx_bell`, `sfx_splash`, `sfx_bite`, `sfx_coins`... полный список в `Scripts/Core/ProceduralSounds.cs`) и `Assets/Audio/Music/music_day.ogg`, `music_night.ogg`, потом **Собрать сцену Main**.
