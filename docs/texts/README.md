# Тексты игры

Отвечает: Сарина. Пишутся обычным текстом в этой папке, Unity не нужна. Ярослав переносит их в данные игры (`DialogueData`, `QuestData`, `NoteData`, `FishData`).

Сюжет и мир берём из [PLAN.md](../PLAN.md): Сымон, дед Язэп пропал 3 года назад, деревня Тихие Вирки, колокол маяка в 20:00, биостанция против Вадзяніка.

| Файл | Что внутри | Нужен к этапу |
|---|---|---|
| `fish.md` | описания 14 записей журнала | первые 4 к этапу 8, остальные к этапам 11, 17, 20, 22 |
| `dialogues.md` | диалоги Тараса и Михалыча | 13 |
| `quests.md` | 5 квестов | 13 |
| `lore.md` | «тайна за редкую рыбу»: кусочки, которые рассказывает Тарас | 13 |
| `diary.md` | 5 страниц дневника деда | 20 |
| `finale.md` | правда о деде, слова Хозяина Омута, титры | 22 |

## Как оформлять

**Рыба** (`fish.md`):

```
## 1. Карась
Описание для журнала: 1–2 предложения.
```

**Диалог** (`dialogues.md`): у каждой реплики свой номер, чтобы на неё можно было сослаться.

```
## Тарас: первая встреча
T-01 Тарас: Ты внук Язэпа? Похож.
T-02 Сымон: ...
Варианты ответа: [Продать рыбу] → T-10, [Уйти] → конец
```

**Квест** (`quests.md`):

```
## Q-1. Название
Кто даёт: Тарас
Цель: поймать 3 карася
Награда: 50 монет
Текст при выдаче: ...
Текст при сдаче: ...
```

**Страница дневника** (`diary.md`): `## Страница 1` и текст, примерно 5–8 предложений.

Короткие строки, без длинных абзацев: на экране мало места.
