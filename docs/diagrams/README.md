# Диаграммы

Отвечает: Сарина. Рисовать в https://app.diagrams.net (draw.io, работает в браузере на Windows и Mac). Сохранять `.drawio` и рядом экспорт `.png` с тем же именем.

Каждую диаграмму рисуем **после** того, как готов этап из [PLAN.md](../PLAN.md), тогда она совпадает с игрой.

| Диаграмма | Что показывает | Когда (этап) | Патч | Файл | Готово |

| BPMN | процесс патча: задача → ветка → PR → ревью → `dev` → `main` | сразу | 0.1 | `bpmn-patch.drawio` | ⬜ |
