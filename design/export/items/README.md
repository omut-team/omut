# Иконки предметов: Удочки и Наживки

Готовые PNG текстуры для игры «Омут». Исходные векторные файлы SVG лежат в `design/src/liza/items/`.

## 🪱 Наживки (32x32 px)
- `item_worm.png` — Дождевой червь на крючке (мирная рыба: карась, лещ, линь, карп)
- `item_spoon.png` — Колеблющаяся блесна «Омутовка» (хищники: окунь, щука, судак)
- `item_spoon_phosphor.png` — Фосфорная блесна (ночные мутанты: угорь, слепыш, двухголовый окунь)
- `item_maggot.png` — Личинки короеда / опарыши (быстрый клёв)
- `item_dough.png` — Ароматное тесто с анисом (трофейный карп)
- `item_glow_leech.png` — Болотная светящаяся пиявка (чёрный сом)

## 🎣 Удочки (64x64 px HD)
- `item_rod_bamboo.png` — Бамбуковая удочка Язэпа (стартовая)
- `item_rod_telescopic.png` — Советский телескоп «Каскад» (универсальная)
- `item_rod_spinning.png` — Карбоновый спиннинг «Полесье» (спиннинг для блесны)
- `item_rod_feeder.png` — Тяжёлый донный фидер «Глубина» (донная ловля, сом)
- `item_rod_magnetic.png` — Поисковая магнитная снасть (сундучки деда, металлолом)
- `item_rod_mystic.png` — Удочка Хозяина (мореный дуб, руны Вадзяніка, финальный босс)

## Настройки импорта в Unity (согласно docs/ART.md):
- **Texture Type:** Sprite (2D and UI)
- **Pixels Per Unit:** 32 (для 1 клетки трюма) или 64 (под размер 64x64)
- **Filter Mode:** Point (no filter)
- **Compression:** None
